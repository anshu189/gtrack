# Icon

The Gtrak icon set: 43 hand-drawn 24px glyphs, 2px round strokes (some filled), `currentColor`.

- **Consumer provides:** `name`, `size` (default 20), `className`, optional `title`.
- These are **substitutes** — the Figma export contains raster screenshots only, so the source's icons, animal illustrations and brand logos could not be extracted. Replace with licensed originals when you have them; keep the names.
