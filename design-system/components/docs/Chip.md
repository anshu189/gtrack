# Chip

Static tag. Variants: `lang` (language pill, `surface-2`), `muted` (rollover chip on `track`), `soft` (large lavender pill — "Gain 6 kg by October 13"), `streak` (flame count), `neutral` (time), `outline` (goal), `overlay` (labels on photos), `trend`, `success` (banner).

- **Consumer provides:** `children`, optional `icon` and `iconClass`.
- Highlight a number inside a chip with a data colour (`text-fat` for "200 cals").
