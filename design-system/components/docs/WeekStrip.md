# WeekStrip

Seven-day picker at the top of Home. `variant="letters"` (Figma home): weekday letter inside a dashed 32px circle with the date below; future days in `ink-3`. `variant="rings"` (marketing): status rings — `day-over`, `day-met`, dashed empty, ink arc for today.

- **Consumer provides:** `variant`, `days`, `value` + `onChange` (or `defaultValue`).
