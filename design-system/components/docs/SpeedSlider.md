# SpeedSlider

Weekly-pace slider: label, value, three speed marks, a 4pt track (black fill) with a 27pt white thumb, min/mid/max labels and a "Recommended" pill that appears inside the healthy range.

- **Consumer provides:** `label`, `value` + `onChange`, `min`, `max`, `step`, `unit`, `recommended` ([lo, hi]).
- The source uses animal illustrations for the speed marks; these are chevron substitutes.
