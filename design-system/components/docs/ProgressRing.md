# ProgressRing

Round-capped progress ring on the cool `ring-track` (#eff1f7) — the system's signature data mark.

- **Consumer provides:** `value`, `max`, `size`, `stroke`, `color` (CSS colour, e.g. `var(--protein)`), optional `track`, `dashed`, `label`, and centre `children`.
- Home calorie ring: 108/12, ink. Macro rings: 68/6. Plan cards: 66/5 with the value inside.
